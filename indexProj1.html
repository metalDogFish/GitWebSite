Project Perlin (Little Fish)

Random Particle movement using Perlin Noise

Flowfields with persistant particles. Flowfields are created using Perlin noise mapped to a 2d grid.
z-dimension toggle allows flowfields to fluctuate over time.
The curtain toggle hides background grid to focus attention on particle movements.
Each particle adjusts their individual directional movement from nearest local flowfield to create truly random unpredictable movement! This method does a great job simulating a school of little fish moving over flowing green kelp.

This project uses javascript and the P5 library
