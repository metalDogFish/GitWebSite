Project Perlin (Little Fish)

Random Particle movement using Perlin Noise

Flowfields with persistant particles. flowfields are created using Perlin noise mapped to a 2d grid.
z-dimension toggle allows flowfields to fluctuate over time.
curtain toggle hides background grid to focus attention on particle movements. Each particle adjusts their individual directional movement from surrounding flowfield.

This project uses javascript and the P5 library
