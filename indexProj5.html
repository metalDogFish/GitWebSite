Flocking Boids

These flocking boids have been optimized with a quadtree to increase performance and speed.

Before adding a quadtree, performance with 200 boids dropped to 20 frames/sec.
Quadtree was sucessfully grafted into each 3 flocking algorythms; separation(),cohesion() and Align().
We now have 1000 boids flying at 60 frames/sec without lag! a noticable difference in speed, indeed.

This project uses javascript and the P5 library
